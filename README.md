# Учебная платформа

Веб-приложение учебной платформы по поиску, подбору и бронированию преподавателей и академических курсов.

## Стек технологий
- **React 19** (без использования сторонних библиотек, чистые хуки `useState`, `useEffect`, `useMemo`).
- **Vite 6** (быстрая сборка и Hot Module Replacement).
- **Vanilla CSS** с CSS-переменными для легкой поддержки дизайн-системы.

## Соответствие макету Figma и методичке
1. **Шапка сайта (Navbar)**:
   - Ссылки: `Главная`, `Партнеры`, `О нас`, `Лекторы` в серо-голубом фирменном стиле.
   - Плавная прокрутка к соответствующим разделам страницы.
2. **Hero-блок**:
   - Фотография учебной аудитории слева.
   - Заголовок платформы справа («Наши лекторы — признанные специалисты в своих областях...»).
   - Кнопка «НАЙТИ ЛЕКТОРА» для перехода к каталогу.
3. **Блок «О нас»**:
   - Официальный манифест миссии платформы.
   - Ключевые метрики (10 экспертов, 30 авторских дисциплин, 300+ тем, 100% охват форматов).
4. **Блок «Партнеры»**:
   - Карточки компаний **ICL** и **«Татнефть»** с векторными логотипами, подробными описаниями и внешними ссылками ↗.
5. **Блок «Лекторы»**:
   - Портреты всех 10 лекторов (5 мужчин и 5 женщин) с фирменной синей полосой внизу фото.
   - ФИО, образование (вуз, год), стаж и учёная степень.
   - Интерактивное переключение 3 читаемых дисциплин для каждого лектора.
   - Полный перечень 10 тем по каждой дисциплине.
   - Сетка тарифов (индивидуальное занятие, пакеты, интенсивы).
6. **Расширение функционала**:
   - Интерактивный поиск по ФИО, дисциплине или теме занятия.
   - Фильтрация по 8 направлениям и по полу лектора.
   - Модальное окно онлайн-записи с выбором тарифа, формата (онлайн / оффлайн) и расчетом стоимости.
   - Информативный подвал сайта.

## Запуск проекта
Для запуска в режиме разработки:
```bash
npm run dev
```

Для сборки продакшен-бандла:
```bash
npm run build
```
